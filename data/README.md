# data/

The project runs **out of the box on synthetic data** — no download needed.

To train on the **real dataset** from the paper (CDC 2020 BRFSS,
"Personal Key Indicators of Heart Disease"), download it and place the file here as:

```
data/heart_2020_cleaned.csv
```

Kaggle: https://www.kaggle.com/datasets/kamilpytlak/personal-key-indicators-of-heart-disease

The pipeline auto-detects this file and uses it instead of synthetic data.
